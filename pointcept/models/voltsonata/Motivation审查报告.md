## 一、随机掩码存在的具体问题（逐条审查）

### 1.1 问题A：掩码分配与语义难度无关 — ✅ 成立，但需更精确的展示

**现有论证：** 随机掩码对所有体素块以固定概率 $r$ 采样，不区分语义难度。

**审查判断：** 这个问题**客观存在且可被严格证明**，但当前展示方式不够具体。

**具体问题展示方案：**

#### 方案A1：分位数掩码分布实验（核心证据）

在 ScanNet 验证集上，对每个场景执行以下步骤：

1. 使用预训练好的 Volt 编码器提取每个体素块的特征
2. 使用 K=256 个原型计算每个块的小体素级语义熵，聚合为块级难度分数 $d_i$
3. 将所有块按 $d_i$ 分为 4 个分位数区间：Q1(0-25%), Q2(25-50%), Q3(50-75%), Q4(75-100%)
4. 以 50% 掩码比例执行随机掩码 1000 次，统计每个区间被掩码的比例

**预期结果与说服力分析：**
- 随机掩码下，四个区间的掩码比例应接近相等（各约 50%）
- 这**直接证明**随机掩码没有聚焦高难度区域
- 该实验简单、无歧义、可复现，是最核心的证据

**⚠️ 当前缺陷：** Motivation 文档仅定性描述"随机掩码在各区间比例相同"，没有给出具体的实验流程和预期数值。建议补充：

```
├──────────┬──────────┬──────────┬──────────┬──────────┤
│ 掩码策略  │ Q1(低)   │ Q2(中低) │ Q3(中高) │ Q4(高)   │
├──────────┼──────────┼──────────┼──────────┼──────────┤
```

#### 方案A2：相关性散点图（直观证据）

**当前设计的缺陷：** 文档中提到"语义熵 vs 掩码概率散点图"，但对随机掩码来说这个图**没有意义**——因为随机掩码的概率是常数 $r$，所有点都在一条水平线上。这不是"散点图"，是一条直线。

**改进方案：** 改为展示**掩码实际覆盖率**（掩码次数 / 总次数）与语义难度的关系：

```
展示：两张并排散点图
  左图（随机掩码）：所有点紧密分布在 y=0.5 水平线附近 → Pearson r ≈ 0
  右图（自适应掩码）：点呈明显正相关趋势 → Pearson r > 0.6

说服力：Pearson r 的定量对比比定性描述有力得多
```

### 1.2 问题B：简单区域的掩码浪费训练信号 — ⚠️ 部分成立，因果链有断裂

**现有论证链：**
1. 平坦区域（低熵）被掩码 → 几何插值即可恢复 → 训练信号弱
2. 高熵区域未被充分掩码 → 训练信号总量不足

**审查判断：** 第1步直觉正确但缺少严格证明；第2步的"训练信号"定义存在循环论证。

#### ⚠️ 关键问题：训练信号强度定义的循环论证

现有定义：$S_i = H_i \times C_i \times G_i$（语义熵 × 类别复杂度 × 几何复杂度）

**问题：** 这个定义**预设了结论**——高熵区域产生更强的训练信号，然后用这个定义证明自适应掩码更好。这是循环论证。

**具体而言：**
- $H_i$ 本身就是语义熵，用它定义训练信号强度，然后得出"高熵区域训练信号强"的结论，逻辑上是同义反复
- 如果训练信号强度的定义不依赖 $H_i$，而是从重构误差或损失梯度直接度量，结论才不循环

**改进方案：** 用**不依赖语义熵的独立度量**定义训练信号强度：

| 度量方式 | 定义 | 优点 | 缺点 |
|---------|------|------|------|
| **重构误差** | $\|\hat{f}_i - f_i\|^2$（学生对掩码块的预测与教师特征的差距） | 直接度量预测难度，不循环 | 需要训练模型后才能度量 |
| **损失梯度范数** | $\|\nabla_{\theta} \mathcal{L}_i\|$（单个块对损失的梯度范数） | 直接度量训练贡献 | 计算开销大，且梯度受模型状态影响 |
| **特征方差** | $\text{Var}(f_i)$（教师特征在块内的方差） | 不依赖原型分配，独立度量 | 可能与语义熵不一致 |

**推荐方案：使用重构误差作为训练信号的独立度量**

```python
# 实验设计：重构误差与语义熵的关系
# 1. 使用预训练的 Volt+Sonata 教师网络
# 2. 对每个场景，掩码单个体素块 v_i
# 3. 学生网络预测被掩码块的特征
# 4. 计算重构误差 e_i = ||f_i^student - f_i^teacher||^2
# 5. 绘制 e_i vs d_i 的散点图

# 预期结果：
# - 如果 e_i 与 d_i 正相关 → 高熵区域确实更难预测 → 训练信号强
# - 如果 e_i 与 d_i 无关 → 语义熵不能预测预测难度 → 自适应掩码的动机不成立
# - 如果 e_i 与 d_i 负相关 → 与假设矛盾 → 需要重新审视动机
```

**说服力分析：** 重构误差是"预测难度"的**金标准度量**。如果它确实与语义熵正相关，则建立了从"熵高"到"预测难"到"训练信号强"的完整因果链，消除了循环论证。

### 1.3 问题C：训练效率低下 — ❌ 论证最弱，需根本性重构

**现有论证：** "相同的掩码比例，随机掩码产生的训练信号最少，需要更多训练迭代达到相同性能。"

**审查判断：** 这个论证有三个问题：

1. **"训练效率"定义模糊**：是达到相同性能的迭代次数？还是相同迭代的最终性能？还是收敛速度？三种含义的证明难度和实验设计完全不同。

2. **"30-50%效率提升"缺乏依据**：文档中给出这个数字但没有任何推导或实验支撑，属于断言而非论证。

3. **效率提升 ≠ 性能提升**：即使自适应掩码的训练信号更强，也可能只是"更快收敛"而非"收敛到更好的点"。后者才是真正有价值的结论。

**改进方案：** 将"训练效率"拆分为两个可独立验证的子命题：

```
命题C1（收敛速度）：在相同训练步数下，自适应掩码的验证损失更低
  → 实验：绘制 training curve，对比相同 checkpoint 的验证损失

命题C2（最终性能）：在充分训练后，自适应掩码的下游任务性能更好
  → 实验：预训练完成后，在 ScanNet 语义分割上微调，对比 mIoU
```

### 1.4 问题D：细小物体的训练不稳定 — ❌ 不成立（已移除）

**现有论证：** "细小物体（杯子、键盘）可能被随机掩码完全遮蔽或完全不遮蔽，训练不稳定。"

**审查判断：** 这个论证**不成立**，原因如下：

掩码是在**体素块（token）级别**操作的，不是在物体级别。一个"细小物体"可能只占 1-2 个 token，也可能跟大物体共享 token。"细小物体被完全遮蔽"在 token 级别掩码下没有清晰定义——一个 token 可能同时包含多个物体的点，掩码这个 token 并不等于掩码某个特定物体。

因此，"细小物体完全遮蔽概率"无法在 token 掩码框架下严谨计算，该论证应从 Motivation 中移除。

## 二、自适应掩码必要性的论证审查

### 2.1 论证结构分析

当前论证结构：
```
观察：语义熵分布不均匀
  ↓（隐含假设1：高熵区域预测更难）
问题：随机掩码浪费在简单区域
  ↓（隐含假设2：聚焦困难区域能提升训练）
方案：自适应掩码聚焦高熵区域
  ↓（隐含假设3：课程学习保证稳定性）
结论：自适应掩码优于随机掩码
```

**三个隐含假设的审查：**

| 隐含假设 | 审查状态 | 需要的证据 |
|---------|---------|-----------|
| H1: 高熵区域预测更难 | ⚠️ 未直接验证 | 重构误差与熵的正相关性实验 |
| H2: 聚焦困难区域提升训练 | ❌ 未验证，且有替代解释 | 对比实验 + 控制实验（见下） |
| H3: 课程学习保证稳定性 | ✅ 部分成立（预热期合理） | 消融实验：去掉课程学习的训练曲线 |

### 2.2 ⚠️ 关键缺失：控制实验（反事实基线）

当前实验设计缺少**控制实验**，无法排除替代解释：

| 替代解释 | 含义 | 排除该解释的控制实验 |
|---------|------|-------------------|
| **不是"聚焦困难"有效，而是"避免简单"有效** | 关键在于不掩码简单区域，而非掩码困难区域 | 逆自适应掩码：只掩码低熵区域，保留高熵区域 |
| **不是语义信息有效，而是任何非随机分布都有效** | 只要掩码分布不是均匀的就有提升 | 随机非均匀掩码：用随机但非均匀的分布（如 Beta 分布采样） |
| **不是自适应有效，而是"看到了更多样的模式"有效** | 自适应掩码让模型看到了更多不同的掩码模式 | 固定模式掩码：按固定规则掩码（如每隔N个块掩一个） |

**必须添加的控制实验设计：**

```
控制实验1：逆自适应掩码（Inverse-Adaptive）
  - 掩码概率与语义熵负相关：低熵区域优先掩码，高熵区域优先保留
  - 如果逆自适应掩码性能 < 随机掩码 < 自适应掩码
    → 证明"聚焦困难区域"是关键，而非"非均匀分布"
  - 如果逆自适应掩码性能 ≈ 随机掩码
    → 说明只要不掩码简单区域就有提升，"聚焦困难"不是必要条件
  - 如果逆自适应掩码性能 > 随机掩码
    → 与假设矛盾，需要重新审视动机

控制实验2：随机非均匀掩码（Random-NonUniform）
  - 每个块的掩码概率从 Beta(2,2) 采样（非均匀但与语义无关）
  - 如果性能 ≈ 随机掩码 → 证明"与语义对齐"是关键
  - 如果性能 > 随机掩码 → 需要进一步分析

控制实验3：密度自适应掩码（Density-Adaptive）
  - 基于点云密度（非语义信号）决定掩码概率
  - 如果性能 < 语义自适应 → 证明语义信息比几何信息更重要
  - 如果性能 ≈ 语义自适应 → 语义熵可能只是密度的代理
```

**说服力分析：** 控制实验1（逆自适应）是最关键的控制实验。如果没有它，即使自适应掩码效果好，也无法证明原因是"聚焦困难区域"而非其他因素。

### 2.3 ✅ 全量块对齐：本就是原有行为，非本方案修改

代码注释明确写道（`volt_sonata_sam.py:601-605`）：

> `"full_block_alignment" flag is kept for API compatibility but the behavior is equivalent since match_neighbour already covers all points in the student output.`

Sonata 的 `match_neighbour` 本就匹配学生输出的**全部点**（包括被掩码块通过 attention 推理出的点），损失天然覆盖所有块。`full_block_alignment` 参数仅为 API 兼容保留，实际行为无区别。

**审查结论：** "全量块对齐是本方案的必要配套修改"这一论证**不成立**——它本就是 Sonata 的默认行为，并非自适应掩码带来的改动。原审查报告中关于此点的 exp5 消融实验设计应移除。

## 五、具体实验方案的详细设计

### 5.1 核心实验1：重构误差与语义熵的相关性

```python
"""
目的：建立"高熵 → 预测难"的因果链（消除循环论证）
方法：逐块掩码，测量重构误差
"""
def experiment_reconstruction_error_vs_entropy():
    # 1. 加载预训练的 Volt+Sonata 教师网络
    teacher = load_pretrained_teacher()
    student = load_pretrained_student()  # EMA copy

    # 2. 对每个场景
    for scene in scannet_val:
        # 体素化
        voxels, occupancy = voxelizer(scene)

        # 教师前向（完整视图）
        teacher_features = teacher(voxels)  # [M, D]

        # 计算每个块的语义熵（使用SDE模块）
        block_difficulty, _ = sde(teacher_features, occupancy)  # [M]

        # 逐块掩码，测量重构误差
        reconstruction_errors = []
        for i in range(len(voxels)):
            # 掩码第i个块
            masked_voxels = apply_mask(voxels, mask_index=i)

            # 学生前向（掩码视图）
            student_features = student(masked_voxels)  # [M, D]

            # 重构误差：被掩码块的特征差距
            error = F.mse_loss(student_features[i], teacher_features[i])
            reconstruction_errors.append(error.item())

        # 3. 计算相关性
        pearson_r, p_value = pearsonr(block_difficulty, reconstruction_errors)
        spearman_r, _ = spearmanr(block_difficulty, reconstruction_errors)

    # 4. 输出
    # - 散点图：x=语义难度, y=重构误差
    # - Pearson r 和 p-value
    # - 分位数表：不同难度区间的平均重构误差
```

**判断标准：**
- Pearson r > 0.5 且 p < 0.001 → 因果链成立，动机充分
- 0.3 < r < 0.5 → 因果链部分成立，需补充其他证据
- r < 0.3 → 因果链不成立，需重新审视动机

### 5.2 核心实验2：逆自适应掩码控制实验

```python
"""
目的：排除"任何非均匀分布都有效"的替代解释
方法：对比自适应掩码 vs 逆自适应掩码 vs 随机掩码
"""
def experiment_inverse_adaptive_control():
    configs = {
        'random': {'adaptive': False},
        'adaptive': {'adaptive': True, 'inverse': False},
        'inverse_adaptive': {'adaptive': True, 'inverse': True},
        # inverse=True 时掩码概率与难度负相关
    }

    results = {}
    for name, cfg in configs.items():
        # 训练完整预训练
        model = train_pretrain(cfg, epochs=300)
        # 在 ScanNet 语义分割上微调
        finetune_results = finetune_downstream(model, task='scannet_semseg')
        results[name] = finetune_results

    # 判断逻辑：
    # 如果 adaptive > random > inverse → "聚焦困难"是关键
    # 如果 adaptive > random ≈ inverse → "不掩码困难区域"是关键（但与假设矛盾）
    # 如果 adaptive ≈ random → 自适应掩码无显著效果
    return results
```

### 5.3 核心实验3：全量块对齐消融

```python
"""
目的：证明全量块对齐是自适应掩码的必要配套
方法：2×2 消融实验
"""
def experiment_full_block_alignment_ablation():
    results = {}
    for mask_strategy in ['random', 'adaptive']:
        for loss_scope in ['unmasked_only', 'full_block']:
            cfg = {
                'mask': mask_strategy,
                'loss_scope': loss_scope,
            }
            model = train_pretrain(cfg)
            results[f"{mask_strategy}_{loss_scope}"] = finetune_downstream(model)

    # 关键对比：
    # adaptive_full_block vs adaptive_unmasked_only
    # → 如果前者 >> 后者，证明全量块对齐是必要的
    #
    # adaptive_unmasked_only vs random_unmasked_only
    # → 如果前者 ≈ 后者甚至更差，证明自适应掩码+原版损失无效
    # → 这是非平凡发现：自适应掩码不是简单"更好"，而是需要配套修改
    return results
```

### 7.2 论证逻辑链的最终形态

```
[事实] 语义熵分布不均匀（实验1验证）
    ↓
[事实] 随机掩码不聚焦困难区域（数学可证 + 分位数实验1）
    ↓
[因果] 高熵区域预测更难（重构误差实验2验证，Pearson r > 0.5）

[因果] 聚焦困难区域产生更强训练信号（训练曲线实验验证）
    ↓
[排他] 聚焦困难区域是关键，而非任何非均匀分布（逆自适应控制实验3）
    ↓
[结论] 语义自适应掩码优于随机掩码
```

每一步都有实验支撑，无循环论证，无未排除的替代解释。
