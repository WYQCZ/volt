# 方向一：语义感知的自适应掩码策略（Semantic-Adaptive Masking）

## 一、问题形式化

### 1.1 现有方法的局限

现有方法（MSC、Sonata）的掩码策略：

| 方法 | 掩码策略 | 局限 |
|------|---------|------|
| MSC | 随机掩码体素块 | 掩码位置与语义无关，简单区域和困难区域被等概率掩码 |
| Sonata | 渐进式随机掩码（比例30%→70%，尺寸10cm→40cm） | 掩码位置仍随机，无法聚焦于语义困难区域 |

**核心问题：** 随机掩码假设所有区域的预测难度相同，但实际上：
- **平坦区域**（如大面积墙面、地面）：几何结构简单，即使被掩码，模型也能通过周围点轻松插值恢复，训练信号弱
- **语义边界区域**（如桌椅交界、物体堆叠处）：需要真正的语义理解才能预测被掩码的内容，训练信号强
- **细小物体**（如杯子、键盘）：随机掩码可能完全遮蔽整个物体，或完全不遮蔽，训练不稳定

### 1.2 三层粒度下的语义难度

VoLT的体素化产生三层粒度：**点 → 小体素（Sub-Voxel）→ 体素块（Voxel Block）**。

```
体素块 v_i (Voxel Block)
┌──┬──┬──┬──┐
│s1│s2│s3│s4│  ← 小体素，排列在规则 P×P×P 网格上
├──┼──┼──┼──┤    每个小体素有：网格坐标、占位标志、池化特征
│s5│s6│s7│s8│
├──┼──┼──┼──┤
│..│  │  │  │
└──┴──┴──┴──┘
```

**语义难度可以在小体素级更精细地估计：** 体素块内不同小体素的语义熵可能差异很大——靠近边界的小体素熵高，远离边界的熵低。将小体素级熵**聚合**为块级难度，比直接在块级计算熵更准确。

### 1.3 形式化定义

给定3D场景 $\mathcal{S}$，体素化后得到体素块集合 $\mathcal{V} = \{v_1, v_2, ..., v_M\}$，每个体素块包含 $P^3$ 个小体素。

传统随机掩码：对每个 $v_i$ 以固定概率 $r$ 独立采样 $m_i \sim \text{Bernoulli}(r)$。

语义自适应掩码：对每个 $v_i$ 掩码概率 $r_i = f_\theta(v_i, \mathcal{S})$，其中 $f_\theta$ 基于**小体素级语义熵聚合**计算。

## 三、核心模块设计

### 3.1 小体素特征恢复模块（Sub-Voxel Feature Recovery）

**设计原则：** 轻量级、不引入额外训练阶段、利用小体素网格结构。本模块完全自包含，不依赖任何外部组件。

#### 3.1.1 输入信息

VoLT体素化阶段已经为每个体素块 $v_i$ 计算了以下原始信息（在拉直为Token之前）：

- **小体素网格坐标**：$(x_j, y_j, z_j) \in \{0, 1, ..., P-1\}^3$，$j = 1,...,P^3$
- **占位标志**：$o_j \in [0, 1]$，小体素内点数 / 最大点数（0表示该位置完全空）

此外，编码器**中间层**输出的**块级特征** $\mathbf{f}_i \in \mathbb{R}^D$ 是已有的 Transformer Token 表示（取教师网络第 $L/2$ 层输出，保留更丰富的空间和语义细节）。

**关键：** 小体素信息在VoLT的Token化（拉直+线性映射）过程中被压缩了。本模块在编码器输出之后，**恢复**小体素级信息。

#### 3.1.2 3D位置编码

小体素的网格坐标是**固定的、规则的**，可以直接使用3D正弦位置编码：

$$\mathbf{pe}_j = \text{MLP}_{\text{3DPE}}\left(\left[\sin(\omega_x x_j), \cos(\omega_x x_j), \sin(\omega_y y_j), \cos(\omega_y y_j), \sin(\omega_z z_j), \cos(\omega_z z_j)\right]\right)$$

$$\in \mathbb{R}^{D_e}$$

其中频率 $\omega_x, \omega_y, \omega_z$ 继承VoLT中RoPE的非对称设计思想：
- $\omega_x, \omega_y$：更高的频率容量（水平方向变化多）
- $\omega_z$：较低的频率容量（重力方向变化少）

$\text{MLP}_{\text{3DPE}}$ 结构：Linear(6, $D_e$) → GELU → Linear($D_e$, $D_e$)。参数量极小（~4K），且为固定编码，**计算一次复用**。

#### 3.1.3 小体素特征合成

对体素块 $v_i$ 内的每个小体素 $s_j$，先通过MLP投影，再经过块内轻量自注意力聚合相邻小体素信息：

**Step 1：MLP投影**

$$\mathbf{h}_{i,j}' = \text{MLP}_{\text{proj}}\left([\mathbf{f}_i \| \mathbf{pe}_j \| o_j]\right) \in \mathbb{R}^D$$

其中：
- $\mathbf{f}_i \in \mathbb{R}^D$：VoLT编码器输出的**块级特征**（提供语义上下文）
- $\mathbf{pe}_j \in \mathbb{R}^{D_e}$：小体素在块内的3D位置编码
- $o_j \in [0, 1]$：占位标志（告诉模型该位置是否有内容）
- $\|$：拼接操作

$\text{MLP}_{\text{proj}}$ 结构：Linear($D + D_e + 1$, $D$) → LayerNorm → GELU → Linear($D$, $D$)

**Step 2：块内轻量自注意力**

$$\mathbf{h}_{i,j} = \mathbf{h}_{i,j}' + \text{MHSA}(\mathbf{h}_{i,j}',\ \text{mask}=o_j)$$

在每个体素块内部，对 $P^3$ 个小体素做单头自注意力（$P^3 \leq 64$，注意力矩阵仅 $64 \times 64$），让相邻小体素交换信息。占位标志 $o_j=0$ 的小体素被mask掉，不参与注意力计算。

**为什么需要块内自注意力？** 原始MLP方案中，所有小体素共享同一个块特征 $\mathbf{f}_i$，唯一的区分信号是位置编码。MLP必须仅从位置推断语义差异，负担过重。块内自注意力让小体素之间互相聚合信息，语义边界处的小体素可以"感知"到相邻小体素的语义差异，从而更准确地产生边界特征。

**计算开销：** $O(P^6)$（因为 $P^3$ 个token的自注意力），$P=4$ 时为 $O(64^2) = O(4096)$，可忽略不计。

#### 3.1.4 批量高效实现

由于每个体素块有**固定数量** $P^3$ 个小体素，可以直接用矩阵运算批量处理：

```python
# 输入：
#   block_features: [M, D]      — M个体素块的特征（教师网络中间层输出）
#   grid_coords:    [P³, 3]     — 固定的网格坐标（所有块共享）
#   occupancy:      [M, P³, 1]  — 每个块内小体素的占位标志

# Step 1: 3D位置编码（所有块共享，计算一次）
pe = MLP_3DPE(grid_coords)           # [P³, D_e]

# Step 2: 广播拼接
pe_expanded = pe.unsqueeze(0).expand(M, -1, -1)   # [M, P³, D_e]
f_expanded  = block_features.unsqueeze(1).expand(-1, P³, -1)  # [M, P³, D]

inp = torch.cat([f_expanded, pe_expanded, occupancy], dim=-1)  # [M, P³, D+D_e+1]

# Step 3: 批量投影
H = MLP_proj(inp)  # [M, P³, D]

# Step 4: 块内轻量自注意力
attn_mask = (occupancy.squeeze(-1) == 0)  # [M, P³], True=屏蔽空小体素
H_sa, _ = SubvoxelAttention(H, H, H, key_padding_mask=attn_mask)
H = H + H_sa  # [M, P³, D] — 所有块的所有小体素特征
```

**计算复杂度：** MLP投影 $O(M \cdot P^3 \cdot D)$ + 块内自注意力 $O(M \cdot P^6)$，其中 $P^3$ 固定（如64），可直接利用GPU矩阵乘法，效率极高。

### 3.2 语义难度估计器（Semantic Difficulty Estimator, SDE）

**教师特征层选择：** SDE使用教师网络的**中间层特征**（如第 $L/2$ 层）而非最后一层。原因：最后一层特征经过Sinkhorn-Knopp中心化处理，信息有损；中间层特征保留了更丰富的空间和语义细节，更适合用于语义难度估计。教师网络的中间层特征在前向传播时已计算，不引入额外开销。

#### 3.2.1 小体素级原型分配与熵（Level 1）

利用轻量可学习原型计算每个小体素的语义分配概率。原型矩阵 $\mathbf{C} = [\mathbf{c}_1, ..., \mathbf{c}_K] \in \mathbb{R}^{K \times D}$ 是可学习参数，**通过Sinkhorn-Knopp均衡约束更新**，防止训练早期原型坍缩。

对小体素特征 $\mathbf{h}_{i,j}$，计算与 $K$ 个原型的相似度和分配概率：

$$a_{i,j,k} = \frac{\mathbf{h}_{i,j} \cdot \mathbf{c}_k}{\|\mathbf{h}_{i,j}\| \cdot \|\mathbf{c}_k\|}$$

$$p_{i,j,k} = \text{SinkhornKnopp}\left(\frac{a_{i,j,\cdot}}{\tau}, \text{iterations}=3\right), \quad k = 1,...,K$$

其中Sinkhorn-Knopp通过迭代行列归一化，强制分配概率在batch维度上均衡（每个原型被等概率分配），防止原型坍缩到少数几个。可复用Sonata中已有的SK实现。

小体素级语义熵：

$$H_{i,j} = -\sum_{k=1}^{K} p_{i,j,k} \log p_{i,j,k}$$

**物理含义：**
- $H_{i,j} \to 0$：小体素的原型分配非常确定（明确属于某类语义）
- $H_{i,j} \to \log K$：小体素的原型分配高度不确定（可能处于语义边界）

#### 3.2.2 块级聚合（Level 2）

将 $P^3$ 个小体素的熵聚合成块级难度分数，使用**top-k-percentile聚合**（取熵最高的10%小体素的平均值）：

$$H_i^{\text{block}} = \text{mean}(\text{TopK}(H_{i,j},\ k=\lceil P^3 \times 0.1 \rceil))$$

**为什么用top-k-percentile而非max？** max-pool对单个噪声小体素极其敏感——一个小体素特征恢复的误差就可能导致整个块的难度分数被高估。top-10%取平均保留了max-pool"不遗漏边界块"的保守策略，但对单点噪声有容忍。当 $P=4$ 时，$P^3=64$，top-10%约取6个小体素。

**与块级直接计算熵的区别：** 直接在块级计算熵只能反映"整个块被分配到多少个原型"，无法区分"整个块模糊"（真实困难）和"块内局部边界"（特定区域困难）。小体素级计算 → top-k聚合可以捕捉后者。

#### 3.2.3 空间异质性辅助信号（消融变体，默认关闭）

除了熵，还可以利用原型分布的**空间方差**作为辅助难度信号。空间异质性衡量块内不同位置的原型分配是否一致：

$$\text{Het}_i = \frac{1}{K} \sum_{k=1}^{K} \text{Var}_j(p_{i,j,k}) = \frac{1}{K} \sum_{k=1}^{K} \frac{1}{P^3} \sum_{j=1}^{P^3} (p_{i,j,k} - \bar{p}_{i,k})^2$$

其中 $\bar{p}_{i,k} = \frac{1}{P^3}\sum_j p_{i,j,k}$ 是原型 $k$ 在块内的平均概率。

**为什么降级为消融变体？** 理论上Het和熵正交（前者衡量"块内不同位置属于不同东西"，后者衡量"单个位置属于什么不确定"），但在方案最关注的**语义边界处**，两者会同时高——小体素本身就在两种语义之间摇摆，熵高且Het也高，存在信息冗余。Het的计算复杂度比熵高（需要计算方差），但增益不确定。因此将Het作为消融实验的一个变体验证，而非默认开启。如果消融证明Het有增益再加回来。

**默认难度公式（仅使用熵）：**

$$\text{difficulty}_i = \frac{H_i^{\text{block}}}{H_{\max}}$$

其中 $H_{\max} = \log K$。

**可选扩展（消融验证）：** 在消融实验中测试混合公式 $\text{difficulty}_i = \alpha \cdot \frac{H_i^{\text{block}}}{H_{\max}} + (1-\alpha) \cdot \frac{\text{Het}_i}{\text{Het}_{\max}}$（$\alpha=0.6$），验证Het的增益。

### 3.3 掩码概率映射

将块级难度分数映射为掩码概率，使用**Sigmoid独立映射**（替代跨块Softmax归一化）：

$$r_i = \text{clip}\left(r_{\text{target}} + 2 r_{\text{target}} \cdot \sigma\left(\frac{\text{difficulty}_i - \widetilde{\text{difficulty}}}{\tau_m}\right),\ 0.05,\ 0.95\right)$$

其中 $\sigma$ 是sigmoid函数，$\widetilde{\text{difficulty}}$ 是当前batch中难度分数的中位数，$\tau_m$ 控制映射的陡峭程度。

**为什么用Sigmoid替代Softmax？** 原始Softmax跨块归一化存在三个问题：
1. **batch依赖性**：同一块在不同batch中，即使难度相同，掩码概率也不同（取决于其他块的难度）
2. **过度集中**：采到简单场景batch时，少数难度较高的块会被过度掩码
3. **clamp破坏一致性**：Softmax后乘 target_ratio/mean 再clamp到[0,1]会破坏概率分布

Sigmoid映射让每个块的掩码概率**只取决于自身难度**，中值居中确保平均掩码率在 $r_{\text{target}}$ 附近，上下限clip防止极端情况。

其中 $\tau_m$ 控制掩码分布的尖锐程度：
- $\tau_m \to 0$：退化为阈值二分（高于中值的全掩，低于的不掩）
- $\tau_m \to \infty$：退化为均匀掩码（所有块概率接近 $r_{\text{target}}$）
- 推荐 $\tau_m = 0.5$（实验调优）

最终采样：$m_i \sim \text{Bernoulli}(r_i)$

### 3.4 课程学习调度（Curriculum Scheduling）

**核心思想：** 训练初期模型能力弱，需要简单目标；后期模型能力强，需要困难目标。简化为**两阶段**（预热 → 自适应），用余弦退火平滑过渡。

#### 3.4.1 混合掩码策略

定义当前训练步 $t$，总训练步数 $T$，预热步数 $t_{\text{warmup}}$（前20%训练步）。混合系数使用余弦退火：

$$\alpha(t) = \frac{1}{2}\left(1 - \cos\left(\pi \cdot \text{clamp}\left(\frac{t - t_{\text{warmup}}}{T - t_{\text{warmup}}},\ 0,\ 1\right)\right)\right)$$

- $t < t_{\text{warmup}}$：$\alpha = 0$，纯随机掩码
- $t \geq t_{\text{warmup}}$：$\alpha$ 从0平滑过渡到1（余弦曲线）

最终掩码概率：

$$r_i^{\text{final}}(t) = (1 - \alpha(t)) \cdot r_{\text{random}} + \alpha(t) \cdot r_i^{\text{adaptive}}$$

**为什么用余弦退火替代线性过渡？** 余弦曲线在起始和结束处变化慢、中间变化快，避免了线性过渡中"突然开始使用自适应掩码"导致的训练震荡。

**为什么需要预热？** 训练初期教师网络的特征质量低，小体素级语义熵估计不准确，直接使用自适应掩码可能导致训练不稳定。预热阶段使用随机掩码让模型先建立基本的特征表示，再逐步过渡到自适应掩码。

#### 3.4.2 渐进式掩码尺寸（继承Sonata）

同时保留Sonata的渐进式掩码尺寸策略：
- 掩码尺寸：$s(t) = s_{\min} + (s_{\max} - s_{\min}) \cdot \frac{t}{T}$
  - $s_{\min} = 10\text{cm}$, $s_{\max} = 40\text{cm}$
- 掩码比例：$r_{\text{target}}(t) = r_{\min} + (r_{\max} - r_{\min}) \cdot \frac{t}{T}$
  - $r_{\min} = 0.3$, $r_{\max} = 0.7$

**三个渐进维度同时工作：**
- 掩码尺寸控制**空间尺度难度**（小→大）
- 掩码比例控制**遮蔽程度难度**（少→多）
- 语义自适应控制**任务质量**（随机→聚焦困难区域）

## 四、训练流程

### 4.1 完整训练Pipeline

```
For each training iteration:
    1. 采样一个batch的3D场景
    2. VoLT体素化 → 体素块序列 V
       同时记录小体素信息：grid_coords, occupancy

    3. 【教师网络前向】
       - 教师网络处理全局视图（无掩码）
       - 提取教师特征 F^T = Encoder_T(V)
       - 保留中间层特征 F^T_mid（第L/2层输出，供SDE使用）

    4. 【语义难度估计】（利用教师中间层特征，不额外前向）
       a. 小体素特征恢复：F^T_mid → MLP投影 → 块内自注意力 → 小体素特征 H ∈ R^{M×P³×D}
       b. 小体素级原型分配（SK约束）：p ∈ R^{M×P³×K}
       c. 小体素级熵：H_j ∈ R^{M×P³}
       d. 块级top-k聚合：d_i = topk_mean(H_j) ∈ R^M
       e. 自适应掩码生成：M = {m_1,...,m_M}

    5. 【学生网络前向】
       - 应用掩码 M 到体素块序列
       - 学生网络处理掩码后的序列
       - 提取学生特征 F^S = Encoder_S(V_masked)

    6. 【计算损失】
       - 聚类分配损失（全量块对齐，包括掩码块）
       - 总损失 L = L_cluster = -Σ_{i=1}^{M} q_i^T log p_i^S

    7. 【更新】
       - 反向传播更新学生网络
       - EMA更新教师网络
       - 更新可学习原型
```

### 4.2 损失函数

**关键修改：** 损失函数的求和范围从"仅未掩码块"扩展为**全部块**：

$$\mathcal{L}_{\text{cluster}} = -\sum_{i=1}^{M} \sum_{k=1}^{K} q_{i,k}^T \log p_{i,k}^S$$

其中 $q^T$ 是教师网络生成的经过Sinkhorn-Knopp中心化和锐化的软标签，$p^S$ 是学生网络的预测。

**为什么必须改为全量对齐？** 方案的核心动机是"高语义区域应优先掩码"，但原始Sonata损失只在未掩码块上计算。如果保持原设计：
- 最有语义价值的块被优先掩码 → 它们不直接参与训练
- 学生网络的监督信号只来自"简单区域"（墙面、地面），与核心假设矛盾

全量对齐下，学生对掩码块的特征是从可见块通过attention传播推理出来的，对齐教师就是要求学生正确推理被遮区域——这恰恰是自监督预训练的目标，不构成信息泄露。

**对Sonata原版的最小修改：** 仅将求和范围从 $\{i \in \text{unmasked}\}$ 改为 $\{i = 1,...,M\}$，损失函数形式不变，仍使用Sonata的SK中心化软标签。

## 五、实现细节

### 5.1 计算开销分析

| 组件 | 额外计算 | 说明 |
|------|---------|------|
| 教师特征提取 | **无额外开销** | 教师网络本来就要前向，使用中间层特征 |
| 3D位置编码 | **极小** | 固定的3D正弦编码，计算一次复用 |
| 小体素特征恢复 | **小** | MLP投影 + 块内自注意力，$O(M \cdot P^3 \cdot D + M \cdot P^6)$ |
| 小体素级原型分配+SK | **小** | 矩阵乘法 + Sinkhorn迭代，$O(M \cdot P^3 \cdot K)$ |
| 熵计算 | **极小** | $O(M \cdot P^3 \cdot K)$ |
| top-k聚合 | **极小** | $O(M \cdot P^3)$ |
| 自适应掩码生成 | **极小** | Sigmoid + 采样，$O(M)$ |
| **总计** | **< 5%额外开销** | 教师网络前向仍是主要开销 |

### 5.2 新增参数量

| 组件 | 参数量 | 说明 |
|------|--------|------|
| $\text{MLP}_{\text{3DPE}}$ | ~4K | 3D位置编码（固定不更新） |
| $\text{MLP}_{\text{proj}}$ | ~0.6M | 小体素特征合成 |
| 块内自注意力 | ~0.03M | 单头MHSA（$P^3 \leq 64$） |
| 可学习原型 $\mathbf{C}$ | ~0.1M | $K \times D$（$K=256$, $D=384$） |
| **总计** | **~0.8M** | 相比VoLT编码器（~60M）仅增加 **1.3%** |

### 5.3 关键超参数

| 参数 | 符号 | 推荐值 | 调优范围 |
|------|------|--------|---------|
| 掩码温度 | $\tau_m$ | 0.5 | [0.3, 1.0] |
| 预热步数比例 | $t_{\text{warmup}}/T$ | 20% | [10%, 30%] |
| 原型数量 | K | 256 | [128, 512] |
| 原型温度 | $\tau$ | 0.5 | [0.3, 0.7] |
| 小体素网格尺寸 | $P$ | 4 | [3, 5] |
| 3D位置编码维度 | $D_e$ | 64 | [32, 128] |
| 聚合方式 | — | top-k-percentile(10%) | top-k(5%-20%) / max / mean |
| 块内自注意力头数 | — | 1 | [1, 2] |
| 教师特征层 | — | 中间层(L/2) | [L/4, L/2, L] |

### 5.4 完整伪代码

```python
class SemanticAdaptiveMasking:
    def __init__(self, D, K, D_e=64, P=4):
        self.mlp_3dpe = MLP_3DPE(in_dim=6, hidden=D_e, out=D_e)  # 固定，不更新
        self.mlp_proj  = MLP(D + D_e + 1, D, D)                   # 轻量投影
        self.subvoxel_attn = nn.MultiheadAttention(D, num_heads=1, batch_first=True)
        self.prototypes = nn.Parameter(torch.randn(K, D))          # 可学习原型
        self.tau_prototype = 0.5
        self.tau_mask = 0.5
        self.warmup_ratio = 0.2  # 前20%纯随机

    def compute_mask(
        self,
        block_features,        # [M, D] 教师网络中间层输出的体素块特征
        grid_coords,           # [P³, 3] 固定网格坐标
        occupancy,             # [M, P³, 1] 小体素占位标志
        target_ratio,          # 目标掩码比例 (0.3→0.7 渐进)
        training_progress,     # t/T, 训练进度 [0, 1]
    ):
        M, D = block_features.shape
        P3 = grid_coords.shape[0]

        # ---- Step 1: 小体素特征恢复（MLP + 块内自注意力） ----
        pe = self.mlp_3dpe(grid_coords)                           # [P³, D_e] 固定
        pe_exp = pe.unsqueeze(0).expand(M, -1, -1)                # [M, P³, D_e]
        f_exp  = block_features.unsqueeze(1).expand(-1, P3, -1)   # [M, P³, D]
        inp = torch.cat([f_exp, pe_exp, occupancy], dim=-1)       # [M, P³, D+D_e+1]
        H = self.mlp_proj(inp)                                    # [M, P³, D]

        # 块内轻量自注意力（P³≤64，计算量极小）
        attn_mask = (occupancy.squeeze(-1) == 0)                  # [M, P³]，True=屏蔽
        H_sa, _ = self.subvoxel_attn(H, H, H, key_padding_mask=attn_mask)
        H = H + H_sa                                              # [M, P³, D]

        # ---- Step 2: 小体素级原型分配（SK约束）与熵 ----
        H_norm = F.normalize(H, dim=-1)                           # [M, P³, D]
        C_norm = F.normalize(self.prototypes, dim=-1)             # [K, D]
        sim = torch.matmul(H_norm, C_norm.t())                    # [M, P³, K]

        # Sinkhorn-Knopp均衡约束（复用Sonata的SK实现，3次迭代）
        probs = sinkhorn_knopp(sim / self.tau_prototype, iterations=3)  # [M, P³, K]

        subvoxel_entropy = -torch.sum(
            probs * torch.log(probs + 1e-8), dim=-1
        )                                                          # [M, P³]

        # ---- Step 3: 块级top-k-percentile聚合 ----
        k = max(1, int(P3 * 0.1))  # top 10%
        topk_vals, _ = subvoxel_entropy.topk(k, dim=1)            # [M, k]
        block_entropy = topk_vals.mean(dim=1)                     # [M]

        # ---- Step 4: 难度分数（仅熵） ----
        H_max = math.log(probs.shape[-1])  # log(K)
        difficulty = block_entropy / H_max                        # [M], 归一化到[0,1]

        # ---- Step 5: Sigmoid独立映射（不跨块归一化） ----
        median_diff = difficulty.median().detach()
        adaptive_probs = target_ratio + 2 * target_ratio * torch.sigmoid(
            (difficulty - median_diff) / self.tau_mask
        )
        adaptive_probs = torch.clamp(adaptive_probs, 0.05, 0.95)

        # ---- Step 6: 混合随机掩码（两阶段余弦课程学习） ----
        alpha = self._curriculum_coeff(training_progress)
        random_probs = torch.full_like(adaptive_probs, target_ratio)
        final_probs = (1 - alpha) * random_probs + alpha * adaptive_probs

        # ---- Step 7: 采样掩码 ----
        mask = torch.bernoulli(final_probs)
        return mask  # [M], 1=掩码, 0=保留

    def _curriculum_coeff(self, progress):
        """progress: t/T ∈ [0, 1], 余弦退火过渡"""
        warmup = self.warmup_ratio  # 0.2
        if progress < warmup:
            return 0.0
        else:
            # 余弦退火：从0平滑过渡到1
            t = (progress - warmup) / (1.0 - warmup)
            return 0.5 * (1.0 - math.cos(math.pi * min(t, 1.0)))
```

4. **聚合方式消融**：top-k-percentile vs. max-pool vs. mean-pool

5. **小体素级 vs 块级**：直接在块级计算熵 vs. 小体素级计算后top-k聚合
   - 预期：小体素级top-k聚合 > 块级（核心消融，证明两级聚合的价值）

7. **原型数量 $K$**：128, 256, 512
8. **块内自注意力消融**：有/无块内自注意力（验证轻量自注意力的增益）
9. **损失函数范围消融**：仅未掩码块 vs. 全量块对齐（验证P0修改的必要性）

## 七、与方向三组合的扩展（可选）

本方法设计为**完全独立**，无需方向三即可工作。但如果组合使用方向三（小体素级软原型聚类），可以进一步提升：

| 组件 | 独立使用（方向一） | 组合使用（方向一+三） |
|------|------------------|---------------------|
| 小体素特征恢复 | 方向一自有的轻量MLP + 块内自注意力 | 共享方向三的分解模块 |
| 原型 | 方向一独立维护一套用于难度估计 | 共享方向三的原型（同时用于损失和掩码） |
| 块级标签 | Sonata原始软标签 | 方向三的多峰软标签 |

**组合收益：** 方向三的3D卷积聚合和空间异质性检测更精确，可以为方向一提供更准确的难度估计信号。同时方向一的自适应掩码也能为方向三提供更高质量的训练样本，形成正反馈循环。

## 八、创新点总结

1. 首次在**体素化点云自监督**中利用**两级语义熵聚合**指导掩码——区别于NLP/2D中的块级/patch级自适应掩码，利用体素化产生的规则网格结构，在小体素级计算语义熵再聚合为块级难度
2. 提出**两级语义熵聚合**：小体素级熵（细粒度）→ top-k-percentile聚合（鲁棒且保守，不遗漏边界块）→ 块级难度分数
3. 设计**熵引导的难度估计**，利用原型分配不确定性识别语义困难区域；空间异质性作为可选的消融变体进一步验证
4. 提出**课程式混合掩码调度**（随机→自适应的两阶段余弦过渡），在不破坏训练稳定性的前提下引入自适应掩码
5. 掩码策略与现有自监督框架**高度兼容**，损失函数仅需最小修改（将求和范围从未掩码块扩展为全量块），可应用到MSC、Sonata等框架
6. 整体新增参数量仅 **~0.8M**（VoLT编码器的1.3%），额外计算开销 **< 5%**（利用已有的教师特征，增加轻量MLP投影、块内自注意力和矩阵乘法）
7. **完全独立设计**：不依赖任何外部模块，仅需VoLT体素化提供的占位标志和编码器输出的块级特征即可工作
